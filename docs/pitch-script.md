## 0:00-1:00 · 痛点开场（约 220 字）

> 切到 PPT 第 1 页：标题 + 痛点数据

各位评委好。先讲一组数字：中国 31 到 40 岁的子女里，**29.7% 与父母异地，42.6% 同城不同住**——合起来超过七成不与父母同住。这意味着什么？父母去医院的时候，绝大多数子女不在身边。

接下来会发生三件事：第一，**父母说不清症状**，进了诊室面对医生一紧张，主诉讲不全；第二，**医嘱记不住**，医生说了一长串药名剂量频次，老人当场记不住也写不下；第三，**复诊时间忘掉**，回家后没有提醒。

而子女这边呢？远在他乡，电话里问"妈今天看怎么样"，得到的回答永远是"还行"——情感上想参与，物理上做不到。我们做的，就是**用 AI 填补这块空白**。

## 1:00-2:30 · 核心方案 + 主架构图（约 330 字）

> 切到 PPT 第 2 页：[3 Agent 协作架构图](./diagrams/agent-architecture.html)

我们的方案叫**家庭AI陪诊师**，核心是 3 个 AI Agent 串联，覆盖就诊**诊前、诊中、诊后**全流程。

看这张图，紫色的就是我们的 Agent 主线：

**第一个 Agent 叫主诉澄清 Agent**，在诊前工作。父母打开 App，AI 像个耐心的护士一样，5 轮多轮提问，把"我头晕"扩展成结构化主诉——部位、持续时间、严重程度、伴随症状、既往史。技术用的是智谱 GLM-4-Flash，**1 秒内出下一句提问**。

**第二个 Agent 叫语音转写 Agent**，在诊中工作。父母进了诊室，医生和患者的对话被实时转写——关键是 mosi.cn 的多说话人云端 API 做了**说话人分离**，S01 标医生、S02 标患者，子女在远端就能看到逐段出现的对话文本。

**第三个 Agent 叫摘要生成 Agent**，在诊后工作。基于转写全文，AI 自动整理成结构化摘要：诊断、医嘱、药品列表（含剂量频次疗程）、复诊提醒、注意事项。**约 10 秒生成**。

3 个 Agent 由状态机串起来，状态推进就是 Agent 之间的交接。

## 3:30-5:00 · 算法与数据来源（约 330 字）

> 切回 PPT 第 2 页，放大 3 个 Agent 卡片细节

我们一个个看 Agent 里的算法和数据来源。

**Agent 1 主诉澄清**：算法逻辑是多轮提问 + JSON 结构化输出。我们用 GLM-4-Flash 的 `response_format=json_object` 强制 JSON 输出，再加 schema 字段兜底容错——即便小模型偶发漏字段，前端也会补全。

**Agent 2 语音转写**：算法核心是**多说话人分离 + SSE 流式**。我们用 mosi.cn 的 moss-transcribe-diarize 模型，`diarize=true stream=true`，音频文件上传后通过 SSE 逐段返回。底层用 expo-av 采集 m4a，UI 上对外我们**完全去掉了"录音"概念**，统一叫"语音识别"——用户感知是连续 ASR，文字逐段出现。

**Agent 3 摘要生成**：用 ConsultationSummary schema 约束 LLM 输出，强制提取药品名/剂量/频次/疗程、复诊项、注意事项，并且数组字段做了强制类型转换——保证不会因为 LLM 偶尔输出非数组导致 UI 崩。

数据来源很干净：3 个 Agent 都用**国内云服务商**——智谱（北京）+ mosi.cn，**数据全程不出境**，符合医疗场景的合规底线。

## 5:00-6:30 · 医疗安全 + 隐私 + 边界（约 290 字）

> 切到 PPT 第 3 页：[安全边界与测试结果图](./diagrams/safety-results.html)

医疗场景，安全和隐私是评委必问的，我们提前讲清楚。

**医疗安全**：摘要**仅供沟通辅助，不替代医生诊断**；药品列表**只整理医嘱原文，不推荐用药**；摘要页 UI 显眼位置标注"AI 整理仅供参考，请以医嘱原件为准"。

**隐私保护**：智谱和 mosi.cn 都是**国内服务商**，数据不出境；demo 阶段 auth/DB/Realtime 走内存 mock，零真实数据留存；赛后 key 会迁到 Supabase Edge Function 服务端，不暴露客户端；数据库 RLS 策略已就绪，患者只能查自己的就诊记录。

**产品使用边界**：适用**老年慢性病陪诊**；**不适用**急诊、危重症、手术决策、精神类疾病；使用前提是患者知情同意 + 医生默许旁听录音；责任划分上，AI 整理不等于医疗建议，最终解释权归医生。

3 个 AI Agent + 状态机串联 + 双端实时同步，让不在身边的家属也能全程安心参与父母就医。谢谢评委，期待提问。
